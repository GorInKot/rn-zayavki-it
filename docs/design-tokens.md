# Дизайн-токены фронтенда

Источник истины — [`frontend/design-tokens.json`](../frontend/design-tokens.json). Из него скриптом
генерируется [`frontend/src/tokens.css`](../frontend/src/tokens.css), который импортируется в начале
[`frontend/src/styles.css`](../frontend/src/styles.css). `tokens.css` не редактируется руками — после
правки JSON пересоберите его:

Готового генератора в проекте нет — `tokens.css` собирается вручную по значениям из JSON, либо любым
генератором, читающим тот же JSON-формат (`$value`/`$type`, ссылки вида `{primitive.color.brand.500}`).

## Три слоя

1. **primitive** — сырые значения (`--primitive-color-ink-900`, `--primitive-radius-sm` и т.д.). Напрямую в
   компонентных стилях не используются, нужны только как источник для semantic-слоя.
2. **semantic** — переменные с прежними именами (`--brand`, `--ink`, `--danger`, `--st-review-fg`, `--radius`,
   `--font` и т.д.), на которые ссылается вся остальная вёрстка. Именно этот слой команда портала может
   переопределить в своём `:root`, чтобы привести вкладку к своему оформлению — компонентные и utility-классы
   не трогать.
3. **component** — точечные токены для button/input/card/badge (`--button-primary-bg`, `--input-border`,
   `--card-shadow`, `--badge-radius` и т.п.), которые ссылаются на semantic-слой. Позволяют поменять, например,
   только скругление кнопок, не трогая остальные компоненты.

## Корпоративная палитра

Значения `primitive.color.brand.500` (жёлтый `#f5d80b`), `primitive.color.ink.900` (чёрный `#010206`),
`primitive.color.ink.700` (тёмно-серый `#393939`), `primitive.color.ink.300` (серый `#b9b9b9`) и
`primitive.color.surface.0` (белый `#ffffff`) — официальные корпоративные цвета. `charcoal.900` ссылается
на тот же чёрный, что и `ink.900` (раньше это был отдельный оттенок `#2b2c31`).

`brand.100` (подложка) и `brand.600` (hover) для жёлтого не заданы корпоративным гайдом — вычислены
программно (82% к белому и 12% к чёрному соответственно), при появлении официальных значений — заменить.

`--muted` (приглушённый текст) намеренно **не** переведён на корпоративный серый `#b9b9b9`: на белом фоне
у него контраст ~1.6:1, что не проходит WCAG AA для текста. Оставлен прежний `#5c6068` (~5.7:1). Корпоративный
серый используется только для не-текстовых элементов — границ (`--line`).

## Что не токенизировано

Единичные оттенки, которые встречаются один раз (бордюры alert-ов, dropzone, choice-карточек и т.п.), остались
как есть в `styles.css` — токенизировать имеет смысл то, что переиспользуется в нескольких местах или должно
быть настраиваемым для портала.
